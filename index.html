Математика в формулах

Плоские геометрические фигуры

Главная (Фигуры) Примеры расчетов

1. Квадрат

Свойства: Все стороны равны, углы по 90°.

Площадь: S = a²
Периметр: P = 4a

2. Прямоугольник

Свойства: Противоположные стороны равны, углы по 90°.

Площадь: S = a × b
Периметр: P = 2(a + b)

3. Круг

Свойства: Все точки равноудалены от центра.

Площадь: S = πR²
Длина окружности: C = 2πR

4. Треугольник

Свойства: Сумма углов равна 180°. Площадь можно найти по формуле Герона.

Периметр: P = a + b + c
Площадь (Герон): S = √(p(p-a)(p-b)(p-c)), где p = P/2
